# Dhyey Ghoda: portfolio

Source of https://dhyey3333.github.io (React + TypeScript, Create React App).
Design based on the MIT-licensed [react-portfolio-template](https://github.com/yujisatojr/react-portfolio-template) by Yuji Sato (see LICENSE).

- Content: `src/components/` (Main, Expertise, Timeline, Project, Contact, Footer)
- Images: `src/assets/images/`; public files (resume PDF, og.png, sitemap): `public/`
- Run locally: `npm ci && npm start`
- Publish: `npm run build`, then copy `build/` to the `main` branch of dhyey3333/dhyey3333.github.io
